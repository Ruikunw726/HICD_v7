## 0. 决策原则

| 项 | 内容 |
|----|------|
| 最终目的 | **制图**（城市级目标×状态损毁产品），不是「保住一个大模型」的形式 |
| 默认推进 | 研究与工程可并行：分治链路可做，统一模型可继续训 |
| 主线切换条件 | 受控实验证明统一模型在 **预先写死的判据** 下占优 |
| 决策依据 | 下表指标与阈值；**实验结束后不得改判据** |

**一句话**：统一的是问题定义、标签规范与成图评估；是否共用权重，由对比实验决定。

## 1. 系统定义（对比对象）

| ID | 名称 | 定义 |
|----|------|------|
| **S1** | 统一模型 | 当前 HICD 一类：T1–T4 在同一框架/联合训练下预测 |
| **S2** | 分任务专用 | T1 单独训练；T2 像素级；T3/T4 实例级；**不融合或仅简单拼接** |
| **S3** | 分治 + 统一规范融合 | 各任务用各自较强模型，再按统一类目/状态/坐标合成制图结果 |
| **S4** | 混合（可选） | T1 专用 + 其余统一（现实折中） |

---

## 2. 什么算「统一模型有优势」

必须至少满足 **维度 A 或 B 之一** 明显更好，且 **维度 F（T1 损失）可接受**。  
**统一以 F1、SeK 为准**；实例计数、非法组合率作辅助证据。

| 维度 | 含义 | 主要指标（现行） |
|------|------|------------------|
| **A. 难类 / 长尾** | T3/T4、crater、tower 等 | **逐类 F1**、召回、实例计数误差 |
| **B. 状态解译** | target 条件下的 state | **状态相关 F1**（或 state 的 F1/准确率，与现有脚本一致）+ 非法 (target,state) 率 |
| **C. 类间一致性** | 同一目标状态是否自洽 | 非法组合率 / 图面矛盾数（辅助） |
| **D. 样本效率** | 同等标注下的表现 | 少类/少城设定下的 **F1、SeK** |
| **E. 制图综合** | 端到端产品 | 成图完整度 + **F1/SeK**（融合后整图） |
| **F. T1 代价** | 建筑损毁等制图关键类 | T1 的 **F1、SeK** 相对 S3 的损失 |

**不算优势**

- 仅背景/未变化像素抬高全局指标（SeK 已部分抑制，仍需看变化类 F1）  
- 参数量或算力大幅增加，但 F1/SeK 提升 < 阈值且 seed 间方向不一致  
- 只在一个 seed、一个场景上偶然更好

## 3. 判据（冻结版）

### 3.1 继续主打【统一模型 S1】当且仅当同时满足

1. **结构优势**：在 **A 或 B** 上（以 **F1** 为主，SeK 作全局对照），S1 相对 S3 达到任一：
   - 相对提升 ≥ **10%**，或  
   - 绝对提升 ≥ **3 pt**（同一 **F1** 口径；若比 SeK 则同样用 pt），且 ≥2 个 seed 方向一致；  
2. **制图代价可接受**：T1 的 **F1 与/或 SeK** 上，S1 不低于 S3 超过 **2 pt**（阈值可在 §3.4 覆盖）；  
3. **至少一项不差且最好更好**：C / D / E 中至少一项 S1 ≥ S3（C 或 E 更有说服力；E 以融合后 **F1、SeK** 为准）。

### 3.2 主线改为【分治 + 统一规范融合 S3】若

- S3 在 **制图关键类（T1、T2 主类）与长尾类** 的 **F1**，以及整图 **SeK** 上 **整体 ≥ S1**，且  
- S1 未在 A/B（F1）达到 §3.1 门槛  

### 3.3 主线采用【混合 S4】若

- S1 仅在部分头 / 部分难类 / 状态一致性上赢，  
- T1 等类 S2/S3 的 **F1、SeK** 明显更强  

则论文叙事：**「何处必须联合、何处应分治」** 作为方法结论，而非强行全局统一。

## 8. 对导师汇报口径（三选一，按结果勾选）

**□ 统一胜出**  
> 同一协议下，统一模型在难类/状态的 **F1** 上明显更好，整图 **SeK** 不差或更好，且 T1 的 F1/SeK 损失在阈值内，方法主线继续采用统一框架。

**□ 分治+融合胜出**  
> 分任务训练在关键类 **F1** 与整图 **SeK** 上更有利于制图；统一性保留在标签与成图规范。联合建模的边界写入分析，不作为主产品。

**□ 混合**  
> 仅在结构耦合或难类上需要联合，其余分治；「何处联合」作为针对战争数据形态的方法结论。

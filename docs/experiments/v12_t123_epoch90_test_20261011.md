## 核验与解释边界

本模型test micro比相同90轮val高约0.43个百分点，macro高约4.40个百分点；T1略高、T2接近、T3由64.78%降至62.56%。不同split的类别/状态构成和macro参与组合不同，不能把整体macro较高解释为所有小类别更好。test Vessel F1为58.81%、召回51.64%；其replaced召回12.29%，仍有较多漏检。单次结果不构成相对基线的统计优势或模块因果证据。

独立从106×106联合矩阵重算raw/decoded micro、macro、P/R及所有目标/状态TP/FP/FN，与原JSON精确一致；像素闭合、完整样本数、零同名重叠、分组全量一致及Farm合并规则通过。verification.json保存校验、指标文件hash与验证对照。

官方macro仍按2TP+FP+FN>0的组合平均；本test GT支持组合25个、有效组合28个，无GT但有误预测组合按0纳入。仅GT有支持组合诊断macro=69.6855%，不能替换正式macro。不同split组合支持不同，val/test macro差值不能当作所有稀有状态能力统一变化。

恢复test是此前旧test撤回341条后的子集，非新外部盲测。修复后train/val/test成员互斥、训练从头开始，但单次运行、城市前缀共享、未完整内容/地理footprint审计以及未齐备同协议基线/消融的限制保留。旧共享划分50轮test88.61/68.27是历史，不与本结果作为单因素改进对照。

- 主类别P/R/F1按target与state精确联合匹配，输出TP/FP/FN与GT/pred support。另列target-only定位诊断；state_on_gt_target在共同有效GT目标区域内独立评估状态头，不按预测目标正确筛样本，明确不是完整系统主成绩。逐target-state行用于细分诊断。
- 新实验沿用原v11模型/损失/实际像素标签、数据/采样和预算，本轮更改的是严格验证与报告；不能以“最新标准”为由隐式改变Bridge/T4映射或恢复被ignore类别。T4可见范围需报告。
- 使用原raw state_logits预测支路及原nearest GT空间对齐，协议明确分辨率；refined结果如报告需另标。
- 新best checkpoint按明确严格主指标选择（默认全前景strict_joint微平均F1），宏平均和各任务/类别诊断并报。实现验收包括严格指标数值测试、实际验证调用通路，以及epoch1/50持续多个batch、有限loss、无启动致命错误。

## 用户评估口径更新（2026-10-08）

用户明确否定把完整状态合并为 D/ND 作为当前主任务评估，要求“严格的什么类别就是什么类别”。新主指标按原始目标类别和具体状态的组合精确匹配，added/no-change、damaged/reduced 等组内混淆也计错，replaced保留。旧BDD的分组和0.3/0.7加权仅作为历史协议说明，不能称为新严格F1或与其直接混比。

- 04 数据评估会话负责新增严格联合指标、独立评估入口、数值边界测试及协议说明；另设只读子代理独立复核。
- 新指标同时报告全前景/各任务精确联合micro与macro、每目标定位与严格联合F1、每目标-状态组合的P/R/F1及support，明确背景、GT ignore、none和无支持类别政策。
- 所有统计使用同一GT有效范围；预测none或错目标/错状态不能被选择性丢弃，背景上的假前景计FP。空类无GT且无预测记不可评估，有预测但无GT仍计FP；单状态完美预测应为1。
- 当前v11训练继续按其原协议运行；本轮新增可重评模块/入口，不热切换当前进程、覆盖旧日志或改变模型/损失/数据。旧汇总分数不能反推出严格分数，必须用预测或checkpoint重算。
- 实现/测试完成和真实模型严格重评是两个状态；若没有预测缓存且GPU在训练，本轮不伪造模型成绩、不争抢GPU启动全量推理。完成状态以04的新记录为准。

## 研究决策（截至 2026-09-28）

1. 方法论文优先；P1 为当前重点，P2 样本/迁移、P3 制图应用为后续队列。
2. T1/T2/T3 像素级；T4 实例级。Bridge 从 T2 移到 T4；T4 为 Bridge/Shelter/Pier/Dock/Tank/Crater。
3. 像素级使用真实样本；实例级可研究合成与采样。50x、20x 稀有类过采样在历史像素分支实验中损害主类，已放弃作为当前默认像素方案。不能推广成所有实例采样都无效。
4. 基线采用单模型全类别多任务联合训练，FC-EF-multi / FC-Siam-multi；单任务结果用于历史诊断，不能直接冒充公平主表。旧方案“等待 Siam 队列”须以当前队列状态决定。
5. BDD F_loc/F_clf/F_overall 与 SeK 是当前主要评估口径；标签、split、mask 与各实现仍需核对。
6. GNN、BackgroundSuppressionLoss、T3/T4 改善等是论文候选论点，必须由实际消融与可复现结果支持。

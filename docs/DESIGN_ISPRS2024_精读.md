# DESIGN.md — ISPRS 2024 HGINet 精读 PPT

## Style anchor
- 锚定物：实验室周报精读页（`王瑞琨20231124进展.pptx`「论文阅读」段）
- 气质：学术汇报、克制、信息密度高；不是发布会 deck

## Palette
| 角色 | 色值 | 用途 |
|------|------|------|
| 页面底 | `#FFFFFF` | 全文白底 |
| 标题紫 | `#6E0F6D` | 页眉「论文阅读」、封面装饰、节标题 |
| 标签红 | `#FF0000` | 小节标签（研究背景：/方法核心：…） |
| 正文墨 | `#1A1A1A` | 正文 |
| 关键词蓝 | `#0000FF` | 方法名/指标名强调 |
| 结论暗红 | `#C00000` | 结论与启示 |
| 辅助灰 | `#666666` | 页脚、文献信息 |

## Typography
- 中文：微软雅黑（Windows 可用；与模板一致）
- 西文/数字：Times New Roman（模板混用习惯）
- 页眉节标题：36pt，紫 `#6E0F6D`
- 小节标签：20pt，红 `#FF0000`
- 正文：16–18pt
- 关键数字：18–22pt 加粗

## Layout system
- 幅面：**4:3**，`10.0 × 7.5 in`（严格对齐模板 EMU：9144000×6858000）
- 页眉：左侧「论文阅读」+ 全宽横线（y≈0.84in）
- 页脚：右下页码
- 内容区：左右边距约 0.35–0.5in；每页 1 个主结论 + 证据
- 图：优先原论文 flowchart / 代码可读模块图；无 PDF 原图时用矢量示意 + 数据表
- 密度：每页 3–6 个信息块，避免整页纯长段
